# Pharma Marketing Skills OS

Version: 0.1.0

An open, modular skill system for pharmaceutical marketing, brand management, commercial excellence, sales force effectiveness, launch planning, and market strategy.

## v0.1 Skills
1. market-analysis
2. pharma-segmentation
3. hcp-segmentation
4. brand-positioning
5. competitive-intelligence
6. brand-strategy
7. campaign-planning
8. launch-strategy
9. sales-force-effectiveness
10. brand-plan

## Design principle
Each skill follows:
Input → Analysis Framework → Decision Logic → Output → QA → Evidence

The system is designed to work with AI coding/agent environments and can later be embedded into PharmaLens AI.

## Safety / compliance
- Never invent clinical, regulatory, market, or financial evidence.
- Clearly separate provided data, calculated outputs, assumptions, and recommendations.
- Do not provide medical advice to patients.
- Respect local promotional, regulatory, pharmacovigilance, and company compliance requirements.
