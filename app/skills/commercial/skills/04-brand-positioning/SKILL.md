# Brand Positioning Skill

## Objective
Create defensible pharmaceutical brand positioning based on customer need, evidence, competition and commercial context.

## Framework
1. Define target customer.
2. Identify unmet need.
3. Analyze competitive alternatives.
4. Identify meaningful differentiation.
5. Map evidence/RTBs.
6. Generate positioning options.
7. Stress-test each option.
8. Select recommended positioning.
9. Build message hierarchy.

## Output
- Target
- Need
- Positioning statement
- Differentiator
- Reasons to believe
- Message hierarchy
- Evidence gaps
- Compliance flags

## Rule
Never convert unsupported clinical claims into marketing claims.
