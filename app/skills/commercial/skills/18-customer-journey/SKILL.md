# Customer Journey Skill

## Objective
HCP/customer decision journey and intervention mapping.

## Framework
Define objective → validate inputs → analyze evidence/data → identify insights → generate options → recommend actions → define KPIs → document assumptions and data gaps.

## Outputs
- Executive summary
- Key insights
- Recommendations
- KPIs
- Assumptions
- Evidence/data gaps
- Compliance flags when relevant

## QA
Separate facts, calculations, assumptions and recommendations. Never fabricate evidence.
