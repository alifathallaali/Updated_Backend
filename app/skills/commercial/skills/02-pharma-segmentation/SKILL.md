# Pharma Segmentation Skill

## Objective
Segment pharmaceutical markets, brands, molecules, territories or products for strategic decision-making.

## Possible dimensions
- Growth
- Market share
- Value
- Units
- Therapeutic class
- Molecule
- Lifecycle
- Geography
- Channel
- Strategic importance

## Framework
1. Define segmentation objective.
2. Select dimensions.
3. Normalize data where required.
4. Segment.
5. Profile each segment.
6. Assign strategic meaning.
7. Recommend differentiated actions.

## Outputs
Segment definitions, profiles, opportunity matrix, recommended strategy.

## QA
Segments must be interpretable and actionable, not merely statistically convenient.
